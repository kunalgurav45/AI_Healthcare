# 🏥 AI_Healthcare

An AI-powered Healthcare Intelligence Platform built with *Streamlit, **Python, **NLP, and **Machine Learning* — combining disease prediction, drug recommendation, heart disease risk assessment, and an AI medical chatbot (Medibot) into a single unified dashboard.

---

## 🚀 Features

- 🔐 Secure Login & Signup system
- 📊 Interactive Analytics Dashboard
- 🧬 Disease Prediction using ML models
- 💊 Drug Recommendation system
- ❤️ Heart Disease Risk Assessment
- 🤖 Medibot – AI Healthcare Chatbot (NLP based)
- 🗄️ MongoDB Integration for data storage
